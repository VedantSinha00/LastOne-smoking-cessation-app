# Decisions Applied

| **Decision** | **Resolution** |
|----|----|
| A1 | One profiles table — absorbs user, onboarding_profile, user_profile. No split. |
| A2 | Unified log table with log_type discriminator. craving_log, slip_log, learning_week_log are phantom — queries only. |
| A3 | quit_attempts is source of truth for quit_date. One open row per user (ended_at IS NULL). Restart closes + opens. |
| A4 | savings is derived — no table. Piecewise formula over quit_attempts + log + cpd_change_log + price_change_log. |
| A5 | voice_style is a column on profiles, not a separate table. |
| T-A | quit_date removed from profiles — lives only on quit_attempts. Stage 0 is variable, unbounded. |
| T-B | Streak owns all freeze decrements. Slip Threshold reads freeze_stock only. |
| T-C | cigarette_count added to log. mood extended to craving rows. attempt_id FK on every log row. |
| T-D | cigarettes_per_day (self-reported) is the canonical savings baseline. |
| T-E | Canonical voice enum: steady_and_direct \| emotional_and_understanding \| real_and_practical. Trigger vocabulary unified (10 tokens). tool_score = thumbs +1/−1, lifetime-cumulative. |
| T-F | SOS contact phone is device-only — never stored server-side. |
| T-G | Intensity 1–5 everywhere. once_daily notification tier dropped. days_smoked_in_attempt (not days_smoked_regularly). confirmation_source = sos \| log (collapsed). |
| N2 | dependence_score (2–8) derived at assessment time → maps to dependency_level written to quit_attempts. |
| N4 | Canonical trigger vocabulary: 10 tokens. trigger_times is a separate 'when' dimension, not the cause list. |
| N5 | user_tool_scores keyed by tool_id. Lifetime-cumulative. No attempt_id on this table. |
| U7 | Pause re-engagement track (N-PAU-01–04) added to Notifications. paused_at field added to streak_record. |

# 2. quit_attempts

Source of truth for quit_date and dependency_level. One open row per
user post-onboarding (ended_at IS NULL). Restart closes the current row
and opens a new one.

| **Field** | **Type** | **Required** | **Notes** |
|----|----|----|----|
| attempt_id | integer | Yes | PK. Auto-increment. Increments on restart. |
| user_id | uuid | Yes | FK → profiles.id |
| quit_date | date | No | Nullable until user picks one. Min: onboarding = account_created_at + 3, restart = restart_triggered_at + 3. No max. |
| started_at | timestamptz | Yes | Set when row is created (onboarding complete or restart). |
| ended_at | timestamptz | No | Null = current open attempt. Set to now() on restart. |
| dependency_level | enum | Yes | light \| moderate \| heavy. Written from dependence_score bands (2–3→light, 4–5→moderate, 6–8→heavy). Updated on restart re-assessment. |

**Invariant: Exactly one row per user with ended_at IS NULL
post-onboarding.**

Derived on this table: dependence_score = craving_weight +
first_cig_weight (2–8). Not stored — computed at assessment time to
produce dependency_level.

# 3. log

Unified log table. All user-initiated logging events. Sparse columns —
only fields relevant to log_type are populated; all others are null.

| **Field** | **Type** | **Required** | **Notes** |
|----|----|----|----|
| log_id | uuid | Yes | PK. Auto-generated. |
| user_id | uuid | Yes | FK → profiles.id |
| attempt_id | integer | Yes | FK → quit_attempts.attempt_id. Scope logs to an attempt. |
| log_type | enum | Yes | craving \| overcome \| slip \| note \| sos |
| timestamp | timestamptz | Yes | Auto-captured at commit point. |
| quit_day_number | integer | Yes | Positive = days since quit. 0 = quit day. Negative = pre-quit (Stage 0). |
| current_stage | integer (0–5) | Yes | Stage at time of log. |

| social_context | string\[\] | No | Multi-select chip values. |

|----|----|----|----|

| mood | integer (1–5) | No | Shared column with craving rows. |

**Derived from log (not stored)**

**outcome (Insights):** log_type = 'overcome' → resisted; log_type =
'slip' → slipped

**trigger_tag (Insights):** First value from triggers\[\], or null

**learning_week_log entries:** log WHERE timestamp \< quit_date

**craving_log queries:** log WHERE log_type = 'craving'

**slip_log queries:** log WHERE log_type = 'slip'

**cigarettes_logged_as_smoked:** SUM(cigarette_count) WHERE log_type =
'slip'

**days_smoked_in_attempt:** Distinct days WHERE log_type = 'slip' AND
slip_type = 'return_to_smoking'

**sos_count_24h:** COUNT(\*) WHERE log_type = 'sos' AND timestamp \>=
now − 24h

# 4. streak_record

One row per user. Manages all streak, freeze, consistency, and pause
state.

| **Field** | **Type** | **Required** | **Notes** |
|----|----|----|----|
| user_id | uuid | Yes | PK + FK → profiles.id |
| current_streak_days | integer | Yes | Resets to 0 on full relapse or resume from pause. |
| lifetime_smoke_free_days | integer | Yes | Never decreases. Accumulates across all attempts. |
| longest_streak_ever | integer | Yes | Updated when current_streak_days exceeds it. |
| consistency_rate | float (1dp) | Yes | smoke_free_days_in_attempt / active_days_in_attempt × 100. Shown from Stage 2 (Day 4+). |
| smoke_free_days_in_attempt | integer | Yes | Numerator for consistency_rate. Resets on restart. |
| active_days_in_attempt | integer | Yes | Denominator. Excludes paused days. Resets on restart. |
| freeze_stock | integer | Yes | Current available freezes. Min 0. Decremented by Streak only (not Slip Threshold). |
| freeze_period | integer (0–3) | Yes | Independent of stage. 0 = Days 1–14, 1 = Days 15–28, 2 = Days 29–90, 3 = Days 91+. |
| freeze_max_current_period | integer | Yes | From FREEZE_MATRIX\[dependency_level\]\[freeze_period\]. |
| dependency_level | enum | Yes | light \| moderate \| heavy. Mirrors quit_attempts.dependency_level. |
| dependency_level_pending | enum | No | Nullable. Set when user upgrades tier mid-period. Applied at next freeze boundary. |
| current_stage | integer (0–5) | Yes | From Stage System. Used for display and coaching tone — not for freeze resets. |
| streak_status | enum | Yes | active \| paused \| reset |
| last_confirmed_date | date | Yes | Last day user confirmed status. Drives return modal trigger. |
| streak_start_date | date | Yes | When current streak began. Recalculated on reset or resume. |
| confirmation_source | enum | Yes | sos (SOS 'Better' — reversible same-day) \| log (any log flow A/B/C/D — final). |
| paused_at | timestamptz | No | Null unless paused. Set to now() on pause. Cleared on resume or restart. |

**Freeze Matrix**

| **Period**     | **Light** | **Moderate** | **Heavy** |
|----------------|-----------|--------------|-----------|
| 0 (Days 1–14)  | 2         | 3            | 4         |
| 1 (Days 15–28) | 1         | 2            | 3         |
| 2 (Days 29–90) | 1         | 1            | 2         |
| 3 (Days 91+)   | 0         | 1            | 1         |

# Key Invariants

**1.** One open attempt: Exactly one quit_attempts row per user with
ended_at IS NULL post-onboarding.

**2.** Freeze writer: Only streak_record decrements freeze_stock. Slip
Threshold reads it, never writes.

**3.** Intensity scale: 1–5 everywhere. intensity = 5 triggers SOS
override in Coping Tools.

**4.** Trigger vocabulary: 10 canonical tokens: stress \| boredom \|
social \| habit \| post_meal \| post_chai \| anxiety \| celebration \|
focus \| other. All surfaces use these exact strings.

**5.** Voice enum: steady_and_direct \| emotional_and_understanding \|
real_and_practical. V1 onboarding exposes only the first two; Real &
Practical has no copy yet (deferred).

**6.** few_days slip: Consumes ALL remaining freeze_stock (not just 1).
Does not increment red_flag_count. Routes to C3 Warm, not Slip
Threshold.

**7.** Pause: Does not create or close a quit_attempts row. quit_date
unchanged. Only streak_status = paused and paused_at = now().

**8.** Savings baseline: profiles.cigarettes_per_day (self-reported).
Confirmed/adjusted by D-1 nudge at Stage 0→1 transition. Locks for that
attempt. Re-fires on restart.

**9.** Restart min date: restart_triggered_at + 3, NOT
account_created_at + 3 (which applies to first attempt only).

**10.** SOS contact: Never stored server-side. Always device-only via
SecureStore.
